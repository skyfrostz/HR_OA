# Pure Admin 与 M3 使用说明

PC 入口为 <http://127.0.0.1:8080/oa.html>，独立手机审批入口为 <http://127.0.0.1:8080/h5.html>。账号沿用原本地环境。PC 使用仓库内的 Pure Admin v7.0.0 源码，来源和改动边界见 `PURE_ADMIN_INTEGRATION.md`。本说明描述已实现的功能；运行验收结果以对应验证报告为准。

## 人事管理

管理员可在“部门管理”新增部门、设置上级或修改名称。部门名称不能重复，不能形成循环。已有员工的部门会在升级时建立关联；修改部门名称会同步更新关联员工的显示名称。

“员工档案”支持查看和编辑工号、姓名、部门、出生日期、入职日期及约定工资。年龄和工龄按日期计算。多人编辑同一记录时，旧版本不能覆盖已保存的新版本；发生冲突后重新读取再修改。

员工详情中的年度年假按半天记录额度和已用天数，余额由两者相减。它是人工登记台账，不自动计算法定应休额度，也不随审批通过自动扣减。

人事查阅员只读全部员工，但看不到工资字段；员工和审批人仅查看本人档案。导出沿用相同的行和工资权限。

## Excel 导入导出

1. 管理员先建立所需部门，再在“Excel 导入”下载模板。
2. 保留“员工导入”工作表及六列表头，填写工号、姓名、部门、出生日期、入职日期和约定工资（元）。日期填写 `YYYY-MM-DD`，工资最多两位小数。文件不超过 2 MiB，最多 1000 条非空记录。
3. 上传后核对逐行结果。有错误时先修改原文件并重新预览；确认导入只会新增员工，不会覆盖现有工号，也不会自动建立登录账号。
4. 预览创建后 30 分钟内确认。如果确认响应丢失，请使用“重试同一预览”取得原结果，避免另建预览。一次确认的员工批次会全部成功或全部回滚。

导入不接受公式、宏、外链或额外工作表。导出为鉴权下载的 Excel 文件，一次最多 5000 条授权记录。查阅员的导出没有工资列；员工和审批人的导出只有本人。

## 合同到期提醒

“合同提醒”显示授权范围内已过期及未来指定天数内到期的合同，可查看对应员工的合同台账。已签署有效续约的前合同会按规则排除。天数按上海时区日历计算。

当前提醒是页面实时查询结果，不是企业微信定时推送。企业微信和阿里云 OSS 已选定，真实账号、消息和云附件接入状态见 `INTEGRATION_STATUS.md`。

## 写入与会话

提交中或结果待确认时，菜单和标签页切换会受到保护。先完成查询或重试，再离开当前操作。令牌及未确认操作只保存在内存；刷新或退出会清除浏览器会话，因此应先核对已有记录。

本地备份入口为 `bash scripts/oa-backup.sh backup`。它短暂停止 API 写入，成对保存数据库和私有附件，然后恢复 API。备份默认位于忽略目录，不能当作已完成的异地备份。隔离恢复脚本只用于独立临时环境验证，不覆盖活动数据卷；详见后续验收报告及脚本帮助。
