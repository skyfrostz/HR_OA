# M4 前端设计与组件选型

2026-11-07，用户在 M4 执行期间追加：检索适配小组件及创新显示形式，用 frontend-design、apple-design 等技能优化美观。本要求叠加于五项业务范围。已阅读两项技能，方向为清晰、稳定、即时反馈的人事工作台，保留 Pure 布局与主题。

## 设计对象与取舍

主要使用者是 HR 与审批人：从名册快速定位员工，在详情中完成账号、合同和历史核查；审批人连续处理任务。最有辨识度的元素是统一的“业务历程”：合同/审批/审计都以真实状态、日期、处理人和原因构成紧凑的时间线。这里只呈现真实事件，未知历史日期明确未知。

头脑风暴对照了三种结构：单长页表单、卡片仪表盘、列表加详情。选列表加详情，保留工作上下文；员工使用侧滑档案，审批使用左右联动。卡片只用于真实状态摘要，避免重复堆叠相同容器。

```text
员工页                              审批中心
[标题/范围/新增]                    [待办 | 已办 | 我的申请]
[部门树] [查询/筛选/表格工具]         [类型/日期/状态筛选]
         [姓名 工号 部门 状态 ...]   [任务队列] [申请正文/真实步骤]
         [分页]                    [分页]     [历史时间线/操作区]
点击档案 -> 侧滑详情                           窄屏转单栏详情
[姓名/工号/状态] [账号/合同/年假/记录]
```

## Token 与排版

浅色以现有主题蓝 #3563E9 为强调，深墨 #182238 为主要文本，次级 #667085，画布 #F5F7FB，面板 #FFFFFF，分隔 #E7EBF2。成功/警告/危险使用 Element Plus 语义 token，不靠颜色单独传达状态。深色全部映射主题 token，不能把浅色边框/灰字硬编码到暗色面板。

标题采用平台 system-ui/PingFang SC（克制的 24–28px 与 650–700 字重）；正文 14–15px、1.5 行高；工号/日期/金额用等宽数字，必要时 ui-monospace。中文正文不加负字距，不下载远程字体。8px 基础间距，正文容器 16–24px；紧凑表格与 44px 窄屏操作目标并存。标题层级与内容密度体现专业感。

### 创新展示形式的落点

- 员工档案：姓名、工号、在职与账号状态构成摘要；账号/合同/年假/变更记录用清晰分组，操作集中在上下文附近。
- 合同卡片：主状态、起止日期、续约关联与真实历史，详情直达；日期不足时不显示虚构进度条，签署登记与电子签名明确区分。
- 审批：列表选中保持位置，详情内申请内容与审批记录并列；底部操作区清楚区分通过、驳回、转交；发起/重提沿用原有幂等语义。
- 审计：字段标签 + 修改前 → 修改后 + 操作者/时间/原因，工资无权者连事件数量都不可借此推断。
- 部门树：直接人数明确标注，当前筛选标签可一键移除；不把直属人数当子树总人数。

## Apple 交互原则的具体应用

按钮 pointer-down 只产生视觉反馈，实际写操作仍在 click/键盘激活后执行；不通过动画延迟提交。抽屉同方向进出、焦点回到触发点。用户可快速切换查看项，过期读请求取消/忽略；写入锁定来自真实提交状态，不能来自动画时间。

普通转换约150–220ms，避免大幅缩放或弹跳。空间变化使用 transform/opacity；仅必要的浮动工具条可轻微透明，内容/表格面板保持可读；prefers-reduced-motion、prefers-reduced-transparency、prefers-contrast 均提供静态/实色退化。不引入声音、触觉、轮播、背景粒子或滚动接管。

## 本轮实际检索与源码边界

- [Element Plus Drawer](https://element-plus.org/en-US/component/drawer.html)：已核对 direction/size/before-close 等接口。线上文档可能比锁定版本新，实施按本项目锁文件校验。
- [VueUse Motion variants](https://motion.vueuse.org/features/variants/) 与 [减少动态效果偏好](https://vueuse.org/core/usepreferredreducedmotion/)：已核对官方文档；本项目已有依赖，优先复用。
- [Inspira UI](https://github.com/unovue/inspira-ui/tree/eec920b047589058b4b02ba64deb614869e7237a)：已浅克隆固定提交，MIT；实际查看 Timeline.vue 与 BlurReveal.vue。前者依赖 motion-v/长页面粘性布局/滚动进度，后者默认 duration=1、delay=2，本轮不原样接入。它的付费 Pro 不属于已获源码授权内容。未将其代码拷入运行产品。
- 本地已有 ReDrawer、ReSegmented、ReSplitPane 等组件；分栏优先 CSS grid，只有真实需要可调整宽度才引入 split 交互。
- 芋道已固定 a33cdfd，实际只参考节点标题、时间和人员的呈现顺序；审批实现复用本仓库 H5 模块，未复制芋道源码、样式、图片或依赖。不是引入流程引擎。详见 [M4 来源记录](M4_SOURCE_REUSE.md)。

## 验收

1440px 与390px浅深色：五项页面实际截图，真实模拟资料与状态；焦点可见/抽屉可退出并恢复焦点/键盘切换，表格工具不泄露工资；浅深色正文对比度抽检至少4.5:1；减少动态效果下无滑动/连续动画；新组件不遮挡底部操作区。总控在QA截图后做视觉复核，必要时退回修正。
