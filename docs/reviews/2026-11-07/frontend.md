# 商业交付审查前端修订

2026-11-07。**前端源码已停止写入，可由 QA 重建并复验。** 本轮仅修改 `web-pure-admin/` 与 `web/` 前端文件。没有重启运行栈，也没有提交或推送。

## 修订内容

- Pure 员工名册使用 `POST /employees/search`，支持按姓名、工号或部门文字查询、精确部门筛选、20/50/100 每页条数、翻页、清空和刷新。HR 管理员与查阅员加载部门选项，员工和审批人使用既有本人权限。提交搜索或切换每页条数后回到第一页。
- 草稿输入与已应用筛选分开保存在内存。导出通过 `POST /employees/export.xlsx` 使用已应用条件，搜索文字和部门条件只走请求体。新搜索会取消旧请求，迟到响应不会替换新结果。用户退出时页面随会话清理。工资及行权限继续由 API 决定。 [接口契约](../../COMMERCIAL_REVIEW_API.md)
- 部门新增和编辑从打开表单起锁住侧栏、标签切换和普通刷新。读请求与冲突后的重新读取分开，普通读取及重试保留草稿。显式取消、写入完成或退出登录会离开编辑状态。
- 移动审批入口卡片使用与其他 Pure 页面相同的主题前景和背景。复现证据由总控保存，修复后的实际深色浏览器对比度由 QA 复验。当前主题入口是顶栏「界面设置」中的「深色」。
- Vant H5 的我的申请、待办、已办、通知提供「刷新」。页面回到前台时重新读取当前列表，保留页码并取消上一请求。
- Pure 冷启动测试改为等待已登录路由、实际侧栏和首张员工表格就绪。首次公开 CI 的默认等待在异步布局与业务页尚未出现时超时。修订去掉登录辅助函数的固定停顿，保留有上限的就绪断言。
