# M6 使用说明

本轮使用合成员工资料和模拟提供商。实际企业微信应用、OSS 资源未准备；配置路径见 [运维说明](M6_OPERATIONS.md)。

## Excel 导入

1. 管理员打开“Excel 导入”，下载模板，填写已有部门名称。先预览，核对总行数、通过行数和错误行数。
2. 切换“仅错误行”定位问题，也可下载错误行工作簿。下载保留原物理行号和错误说明，须修正后重新上传；工作簿含个人资料，应按内部权限保存。
3. 只有全部通过且预览未过期才能确认。预览有效30分钟，过期或离开页面会清理当前预览内容；到期后不能用旧预览继续提交。
4. 若确认请求结果未知，按页面提示读取状态或重试同一预览，避免重新上传后重复创建。成功后源数据清理，导入历史保留摘要与结果。
5. “导入历史”只展示本人创建的记录。完成记录可回看结果，已过期记录不能恢复原员工行内容。

## 合同附件

- 新上传默认“敏感”级，仅人事管理员和合同所属员工账号可见。普通级沿用既有合同读取范围；人事查阅员不能读取敏感附件的元数据、预览或下载。
- 旧附件为兼容既有业务保留普通级。若 PDF/图片包含工资等敏感原文，应由管理员在“访问范围”中改为敏感级并填写原因。隐藏工资字段不会自动脱敏附件。
- “预览”通过授权接口获取图片或 PDF。PDF 以分页图像展示，不提供文档脚本、外部链接或嵌入表单；加密、损坏或超过预览限制时会显示错误，可以关闭后继续操作。需要检索和辅助阅读时使用授权下载。
- 修改分类遇到版本冲突时重新读取当前记录；网络结果未知时先核对，不应盲目覆盖。关闭预览和退出账号会清理当前浏览器内容。

## 企业微信登录和成员绑定

1. 运维先配置服务端应用和固定回调 origin；页面“集成状态”会区分未配置、模拟授权和已配置待企业验收。
2. 管理员在员工详情中先开通或绑定 OA 员工/审批人账号，再进入“企业微信”填写明确的成员 ID 和变更原因。成员标识由服务端规范为小写并检查唯一；不接受广播或多个收件人选择器。
3. 普通 PC 浏览器跳转企业微信官方扫码/桌面授权页；H5 在企业微信内授权。回到 OA 后使用一次性同源票据建立内存会话，URL 不携带 OA 令牌。
4. 未绑定成员、外部联系人、停用或离职账号不能通过授权自动创建身份。绑定、解绑会撤销旧会话。绑定不赋予人事管理角色。

当前模拟模式只用于联调；未配置企业应用时仍可使用原有账号登录。

## 通知与合同到期

“站内通知”区分审批事件和合同到期事件。PC 合同提醒直接打开有权限的目标合同；H5 给出合同提示和 PC 管理端入口。历史事件保留创建时的投递模式。

管理员在“集成状态”的通知处理记录查看：

| 状态 | 含义 |
| --- | --- |
| 本地模拟记录 | 已生成站内模拟通知，没有外部企业投递 |
| 等待处理 | 尚未处理，或明确可重试错误正在退避 |
| API 已接受 | 提供商返回接受，不证明已送达或已读 |
| 处理失败 | 明确失败或重试已耗尽 |
| 结果未知 | 请求结果不确定，系统不盲目重复发送 |
| 已跳过 | 接收人或事件已不满足投递条件 |

合同定时提醒默认关闭，由服务端显式启用。开启后默认扫描未来30天已签署合同，按合同版本、阈值和收件人去重；已终止、有效续约替代或离职的合同不继续投递。人事站内提醒和员工企业提醒的接收范围不同，企业消息只包含通用提示及事件编号，不含合同、工资或申请正文。

页面可用性、权限和错误路径以 [M6 范围](M6_SCOPE.md)及最终验证报告为准。模拟 API 通过不代表真实企业成员、真实 Bucket 或客户生产服务器已验收。
