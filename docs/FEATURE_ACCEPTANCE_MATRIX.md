## 本轮完成标准与后续环境工作

用户已确认“暂未准备，先完成实现与模拟联调”。因此 M6 的开发收口不依赖购买云资源或提供真实密钥，但不能将模拟通过写成企业微信/OSS 客户环境已通过。

正式使用前需提供企业应用及成员映射、私有 Bucket 与限定权限凭据、HTTPS 域名/服务器，以及客户工作日历、额度和审批制度；然后执行真实外部联调和部署验收。现有 GVA BSL 使用条件也需独立落实。

合同电子签名服务、工资自动计算、考勤设备、招聘绩效、多租户和任意流程设计器不在本表既定范围。合同签署登记不等于电子签名。
