## 失败记录、剩余项与边界

- 历次真实 FAIL 均保留：固定栏越界、低对比度、保存刷新后焦点丢失、H5 错误遮挡、320px 顶栏裁切；修复后使用同探针验收，不通过删断言或盲目更新截图消除失败。
- 发布截图首轮合同双激活探针在内容加载中就采样，保留 1 次失败；脚本后续等待明确目标合同内容，同镜像三次通过。未删除失败历史，也未用任意 sleep 掩盖业务结果。
- MySQL 首次用例误用合法年份 1900，改为 0999 后原越界断言通过；原失败日志保留。
- 浏览器复拍遇真实登录 429，遵守 Retry-After 等待；没有弱化限流或换身份绕过。旧导入历史 locator 根据折叠交互展开，真实内容/下载/提交断言保留。
- 两份独立只读视觉审阅与实际浏览器验证分开；Impeccable detector 是补充工具，不代替布局、业务或可访问性验收，也未加忽略规则隐藏问题。
- Chromium H5 原生 date 空值可能显示浏览器的 `dd/mm/yyyy`，页面已有中文标签/说明，API 使用 ISO 日期。物理手机系统日期控件本地化与软键盘尚未实测。
- **NOT RUN**：真实手机及软键盘、客户企业微信/OSS、实际送达/已读、生产 TLS/部署、异机灾备。桌面 Chromium 手机视口、合成数据、本地 mock 不代表上述验收。
