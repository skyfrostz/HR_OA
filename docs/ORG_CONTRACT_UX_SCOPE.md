# 部门组织图与合同原页详情改造

## 目标与已确认决策

基于当前 `246a030`，保留 Pure Admin、品牌蓝、浅深主题及现有权限。

- **部门管理**：默认展示组织结构图，支持浏览、搜索、展开与缩放；通过表单维护上下级，不支持拖拽重组。
- **合同提醒**：原页打开合同详情抽屉，手机全屏展示；不再先跳转员工档案。
- 所有前端代码仍由原前端会话修改，QA 负责真实浏览器验证，总控负责集成与发布。

## 部门管理

- 复用已安装的 **Vue Flow、Dagre** 和现有布局示例；按 Frontend UI Engineering、Apple Design 与项目设计契约适配，不增加组件库或依赖。
- 使用现有 `GET /departments/tree` 获取完整层级，不能把分页列表的某一页当作整棵组织树。
- 桌面采用自上而下的组织图，多根部门分别展示；默认展开前两层。节点展示部门名称、**直属员工数**及下级数量，不虚构公司根节点、负责人或总人数。
- 工具栏提供搜索定位、展开/收起、缩放、恢复视图和“结构图／列表”切换。搜索命中后展开祖先并定位节点；普通刷新保留展开、选中和画布位置。
- 点击节点打开部门详情抽屉；管理员可编辑、新增下级、查看历史，查阅员保持只读。表单在抽屉内切换，不把组织图向下推。
- 上级选项排除自身与后代；服务端继续执行循环、深度及版本检查。保存成功刷新相关数据并保留定位；冲突或失败保留输入并明确反馈。
- 窄屏默认使用带连接线的纵向折叠组织树，仍可切换结构图；长名称可完整查看，操作区域不被画布手势覆盖。
- 布局只在数据、展开集合或容器尺寸实际变化时计算；不因普通点击反复全图布局、缩放。节点不可拖动或连线修改关系。

## 合同详情与切换卡顿

- 从现有合同台账中提取共享的合同详情与操作组件，由员工档案和提醒页共同复用；提醒页不加载员工名册、组织树或该员工全部合同。
- 点击后立即打开固定尺寸的抽屉与加载态，直接请求 `GET /contracts/:id`。核对返回的员工 ID 与提醒对象一致，成功后展示合同摘要、期限、状态、附件及历史。
- 保留原权限和状态允许的编辑草稿、登记签署、续约、终止、附件上传及范围调整。续约仍创建关联草稿，不覆盖旧合同。
- 桌面抽屉最大宽度约 880px，窄屏全屏；固定标题与关闭入口，正文独立滚动。编辑模式在同一抽屉内替换查看内容。
- 移除这条入口中的员工路由跳转、导航意图传递和加载后跨页面自动滚动。抽屉挂载到页面根层，避免受到路由变换容器影响；只保留一次简短位移动画，并响应减少动态效果偏好。
- 使用取消请求与请求序号防止旧响应覆盖新合同；连续点击同一合同只打开一次。关闭后的响应不得重新打开抽屉或抢夺焦点。
- 关闭时恢复触发按钮、筛选、页码及滚动位置。合同变更后刷新当前提醒页；目标不再满足提醒条件时明确提示，分页越界则回到最后有效页。
- 编辑中关闭须明确处理未保存内容；提交中防止重复操作，失败保留输入。403、404、网络错误分别显示明确状态，不残留上一份合同。
- 先记录旧流程的连续画面、请求时序与性能轨迹，区分路由过渡、抽屉布局、请求等待及自动滚动；不沿用上一轮“目标最终打开”的测试代替卡顿验收。

## 接口与兼容

- **不新增后端 API、数据库迁移或依赖升级**。复用部门树、部门写入、合同详情、合同操作、附件和审计接口。
- 前端补充部门树节点类型，明确 `employeeCount` 为当前授权范围内的直属人数。
- 合同详情组件接收合同 ID 和预期员工 ID，通过变更事件通知列表刷新；抽屉负责打开、关闭及焦点，合同组件负责读取和业务操作。
- 提醒列表路由、员工档案入口及通知深链保持兼容；本轮只改变“提醒列表→查看合同”这条交互，不扩大到其他入口重构。

## 验证与交付

- **组织图**：覆盖空数据、多根、长名称、20 层、100/500 节点；验证搜索定位、折叠、视图切换、编辑后定位、只读权限及循环关系拒绝。
- **合同**：覆盖首次打开、快速双击、关闭再打开不同合同、慢响应、乱序响应、403/404/500、编辑取消、版本冲突及续约；回归员工档案中的合同功能。
- **权限**：管理员、人事只读、所属员工、同角色其他员工分别检查附件元数据、预览、下载与范围修改。
- **视觉与性能**：1440×900、1366×768、390×844，补查 320/360px；浅深主题、键盘焦点和减少动态效果。通过连续帧及性能记录确认没有员工页面中间帧、抽屉宽度突变、重复动画或加载后滚动跳动。
- 运行受影响测试、完整 PC 测试、typecheck、build 和修改文件 lint；必要后端回归不重复扩大范围。
- 更新设计契约，交付同条件前后截图、切换过程录像、验证结果与限制。完成本地验收后推送 main，确认对应提交 CI 全部通过；不包含生产部署。
