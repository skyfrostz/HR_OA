# M6：既定功能收口与外部集成实现

日期：2026-11-07。基线：M5 `d2f2fa1026eae443940f0b51a864292c23eab4a8`。用户授权继续完成既定功能；确认企业微信应用和 OSS 资源尚未准备，要求先完成实现与模拟联调。本轮完成的含义是代码、页面、模拟服务契约和本地端到端通过，不等同于客户环境上线。

## 本轮功能与验收

| 功能 | 交付范围 | 验收重点 |
| --- | --- | --- |
| 企业微信身份 | 服务端 OAuth、一次性 state、防重放、已有 OA 员工显式绑定、停用/解绑即时失效、PC/H5 入口 | 未绑定不能自动建号或提权；身份信息不进入日志/浏览器持久存储；伪造和过期授权失败 |
| 企业微信通知 | 现有事务 outbox 接真实服务端适配器；可重试错误、投递状态、最小必要消息内容 | 模拟成功/失效 token/限流/超时/收件人不可达；业务提交不依赖第三方成功；不冒称送达或已读 |
| OSS 私有附件 | 服务端私有对象上传/读取、配置校验、保留本地后端、已有附件可校验迁移 | 每次读取先验证 OA 权限；不返回密钥或公共地址；迁移逐字节校验成功后切换，不删原件；失败可恢复 |
| 附件分级与预览 | 明确普通合同和敏感附件访问策略；受控 PDF/图片预览 | 附件中的工资原文也受访问策略控制；禁止 HTML/SVG 任意内容内联；切页/退出清理 blob URL |
| Excel 导入完善 | 仅错误行、错误导出、预览过期、敏感预览清理、结果回看 | 服务端再校验；跨账号不可查看；不把工资数据或源工作簿永久留在浏览器；下载防公式注入 |
| 运维与持续验收 | 生产配置校验、可信代理、脱敏诊断、版本化迁移、可移植备份恢复、独立 MySQL 集成 CI | 默认不信转发头；无开发种子/弱密钥的生产配置；旧数据无损升级；恢复验证数据库和附件；全新 checkout 可执行 CI |

所有新界面沿用 Pure Admin/Vant 的已验收样式、深色和窄屏行为；保留 M1–M5 功能、权限、幂等和历史快照。源码复用必须记录来源和许可证，服务端官方 SDK 优先于自制签名。

## 明确边界

- M5 已有可配置请假类型、工作日历、额度台账和顺序审批；本轮补收口，不重复开发。正式企业制度由使用方配置，演示默认值不冒充客户制度。
- 合同签署登记已实现。法律效力电子签名、薪资计算、考勤设备、招聘绩效、多租户、任意分支会签流程设计器不属于既定承诺。
- 真实企业微信/OSS、客户 HTTPS 域名、生产服务器、异机灾备和实际企业成员的验收未开展；本轮以用户确认的模拟联调完成开发验收。
- 实际生产使用前仍需确认既有 GVA BSL 1.1 授权条件。此项与功能实现分开记录。

后端、前端和 QA 保持现有目录所有权；接口以 M6_API_CONTRACT.md 为准。交付包含逐项证据、真实页面截图、来源清单、main 提交和该提交的 GitHub CI 结果。不能用旧 M5 测试记录代替新增功能验收。
