# M4 操作说明

M4 包含员工账号、合同生命周期、业务变更历史、PC 审批中心及组织名册。是否已通过验收以 M4 验证报告及对应发布提交为准。

## 员工档案与组织名册

在员工档案页选择左侧部门，或提交姓名/工号/部门搜索。部门人数是当前授权范围的直属档案数，包含保留的离职档案；下级部门人数不自动累加。导出使用已经应用的筛选，而非尚未提交的输入。

表格工具提供列选择、密度、全屏和分页跳转。查阅员的工资列不参与列设置，接口及导出同样省略工资。点击查看档案打开员工详情；详情中的编辑需保存或取消后才能关闭/切换，退出登录会结束当前编辑。

## 员工账号

管理员在员工详情的账号区域操作：

- 开通账号：填写唯一用户名、12–72 UTF-8 字节的新密码、员工/审批人角色和原因。账号绑定该员工后才能访问本人档案；密码不显示在结果、历史或日志中。
- 绑定现有账号：从尚未绑定的员工/审批人账号中选择；原角色和启用状态保留，不覆盖密码。
- 重置密码或变更角色：旧会话失效；普通员工资料编辑不会恢复登录。
- 停用登录：保留在职状态和档案；后续可重新启用，但旧 token 不会复活。
- 办理离职：标记已离职，停用账号并保留历史。当前版本不提供撤销离职或返聘入口。

本轮账号管理只支持 EMPLOYEE/APPROVER，不能用于创建或修改 HR_ADMIN/HR_VIEWER，也不能管理自己的账号。无账号员工也可以办理离职。

审批人有当前待办、未来节点或演示默认路径责任时，选择交接人后才能停用、移除审批角色或离职。系统检查交接人是否可用以及是否会造成申请人自审批；冲突时整笔操作不会部分成功。原审批路径快照保留，转交历史和实际任务说明后续责任人；重新启用原账号不会撤销已完成交接。

## 合同

新界面新增/续约先建立草稿。草稿可编辑编号和起止日期；登记签署后可登记终止。每次操作填写原因和当前版本，遇到版本冲突必须重新读取核对。登记签署记录线下事实，不提供电子签名或签章认证。

续约产生关联的新合同，原合同与附件继续保留。合同到期提醒直接读取所选合同，即使它不在员工合同列表第一页也可定位。历史记录没有明确签署/终止日期时保持未知，不用迁移时间代替。

## 业务变更历史

工资、部门、年假、合同、账号和在职状态的新增变更会显示操作者编号、时间、动作及前后字段。M4 之前没有记录的事件不会回填虚构历史。非管理员不返回自由填写的原因文本；查阅员完全看不到工资事件及其数量，员工和审批人只查看本人可见记录。

原因中不要填写密码、证件号码等无关敏感信息。附件原文仍沿用既有授权：隐藏结构化工资字段并不会自动遮盖合同 PDF 中的工资。

## PC 审批中心

按权限进入我的申请、待办和已办；按类型、状态、日期筛选。点击记录查看正文、步骤和处理历史，可以发起、审批、驳回、转交或基于驳回申请重提。PC 与手机审批共用同一后台，处理后另一端刷新可看到结果。

待办只包含进行中的申请；筛选其他状态会得到空列表。三个列表的日期范围分别对应申请、待办任务、已办动作的创建日期，采用上海业务日期。展示的步骤和数据来自后台，未提供会签或自定义流程设计器。

## 写入结果不明

账号/合同请求超时或服务异常时，页面不会自动重复提交。使用重新读取，核对状态及变更记录后再决定是否继续。审批沿用同一操作意图的幂等键重试，不能通过多次点按钮创建新的操作。

## 显示与操作

浅色、深色和窄屏均可使用。表格与详情保留键盘焦点提示；系统设置减少动态效果时采用静态或淡入反馈。真实业务入口和权限优先于动画效果。
