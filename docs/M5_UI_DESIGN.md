# M5 界面增量

延续 [M4 设计](M4_UI_DESIGN.md) 的 Pure 布局、蓝色强调、浅深色语义 token、中文系统字体和紧凑表格；本轮增加信息与操作，不更换视觉体系。使用 frontend-design、apple-design 与 Vue 实践技能。

## 页面结构

- 工作台：真实授权计数配直接入口，显示加载、失败和空状态，不使用演示数字或虚构趋势。
- 请假表单：类型、日期与半天在同一上下文；计算结果分离展示实际工作时长、年度分摊和额度问题，变更输入后清除过期结果。
- 年度余额：人工已用、审批已用、预占、可用明确分开，流水以业务事件和申请编号追溯，不把所有已用混在可编辑输入中。
- 管理配置：受限表单维护类型、日历例外及顺序审批人；优先级、直属部门和金额边界直接说明，保留版本冲突反馈。
- 异常处理：列表摘要与原因、当前或未来步骤、有效接手人；不会以一个详情按钮扩大私人表单权限。

## 交互检查

预览只负责解释服务端计算，不替代提交校验。输入变动、配置过期、余额冲突都有明确反馈。未知写入沿用现有幂等重试锁；配置表单沿用版本检查。撤回、撤销和交接要求明确原因，按钮使用真实进行中状态控制。

保持 390px 单栏和 1440px 桌面体验；表格、日期输入、步骤列表不能产生页面横向溢出。浅深色下正文和关键计数清晰；焦点可见，键盘能完成选择、退出和提交，减少动态效果时不增加滑动或持续数字动画。截图必须来自最终真实应用与模拟资料，不能以设计稿或旧版本截图替代。

## 复用边界

优先使用已导入的 Pure、Element Plus、Vant 与现有 OA 审批/幂等组件。统计展示可复用现有 Statistic 示例的组件用法，不能复制演示数值或倒计时。工作台、表单、列表只连接当前后端支持的操作；不为视觉效果增加独立流程引擎、全局样式系统或无关依赖。实际适配文件在 [M5 源码复用记录](M5_SOURCE_REUSE.md) 完成后列出。
